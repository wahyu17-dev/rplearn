CSS

CSS digunakan untuk mengatur tampilan elemen HTML.

Konsep yang dipelajari

Mulai dari syntax, variabel, tipe data, operator, kondisi, perulangan, fungsi, struktur data, dan konsep lanjutan yang sesuai dengan bahasa ini.

Contoh sederhana

body {
    background: #f7f7f7;
}

Tips belajar

Jangan hanya membaca kode. Ketik ulang, ubah nilainya, jalankan, lalu amati hasilnya.

Latihan

Coba: Buat satu card dan atur warna, jarak, border, serta efek hover.
Target:

Pahami syntax dasar sebelum masuk ke konsep yang lebih lanjut.
